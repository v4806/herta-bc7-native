# 已验证加速方案正式接入黑塔4

日期：2026-10-25。安装根目录：`D:/Program Files/Blender Foundation/scripts/addons/TheHerta4-main`。

本轮用户明确要求将已经检验的方案落盘、替换原来的低效率路径。原生内存编码器已从实验目录接入正式转码入口；此前已接入的解码、缓存和几何哈希路径也已核对。

## 已启用的路径

| 功能 | 安装后的行为 |
|---|---|
| DDS 相似度/像素解码 | 原生 C BC7 解码与融合 RGB 特征提取；相似度 16、像素模式 32 线程，保留兼容解码回退 |
| PNG→BC7 DDS 编码 | 支持的输入默认使用原生内存流水线，16 个对象任务并行；不经过 texconv/RGBA 中间文件 |
| 不支持的源容器、精度、格式等 | 继续按原配置走 texconv 合批；必要时保留原来的单项/原图回退 |
| 完整 DDS 磁盘缓存 | 源内容、格式、色彩/mip/质量规则与编码器摘要匹配时，直接恢复产物；默认 8 GiB 软预算 |
| 几何哈希 | 连续权重数组、自制 C 打包、最多 8 个对象任务并行、同批相同 Object 复用；原哈希字节保持一致 |
| 日志 | 原生批量编码、缓存、几何提取/哈希、Element 求值/切线/属性等分项可观测 |

正式转码顺序为：**原节点完成查重/覆盖决定 → 复用已验证产物缓存 → 支持任务原生并行编码 → 剩余任务 texconv 合批/原回退**。已有目标的判断没有移交给缓存或编码器，继续使用用户所选资源合并节点的机制与配置。

格式仍由现有 `resolve_texture_dds_format` 解析工作空间、覆盖设置和规则，原生路径只接收 `bc7_unorm`/`bc7_unorm_srgb`。其它格式不会擅自改为 BC7。几何路径未改拓扑、权重值、UV、形态键或索引顺序。

## 原生编码器落盘与兼容

- 正式入口：`toolkit/dds_native_encoder.py`，已被 `tt_dds_conversion.py` 的单张、导出期缓存和新目标批量路径调用。
- 二进制：`common/native/bc7f/herta_texture_windows_x64.dll`。
- C++ 封装、PNG 头文件、上游许可、构建元数据及 CMake 入口同目录保存；Basis Universal 固定提交 `ee771a7f913a3233a252eb6d281b4446f6a3c9f5`。
- 本轮重新编译为 **Windows x64 SSE2 基线**，移除实验构建的 AVX2 要求。动态 MSVC runtime 不可用、平台/ABI 不匹配或输入不支持时回退 texconv。
- 支持 PNG 内容（包括扩展名是 `.dds` 的 PNG）、已支持位深与色彩信息、2 的幂尺寸、完整 mip。16-bit、自定义 ICC/未知 gamma、非 2 的幂尺寸等保留原编码路径。
- `HERTA_NATIVE_DDS_ENCODER=0` 可仅禁用原生编码；磁盘缓存与 C 解码独立工作。几何 DLL 的回退与 `HERTA_GEOMETRY_NATIVE=0` 保持有效。

BC7 是有损格式，新编码器输出不承诺与 texconv 压缩字节一致；此前已检查相似度、像素误差和透明度限制。本轮保持已验证的部分解析预设。纹理的输出格式和色彩/mip 规则保持现有配置。

## 73 张真实源图的正式转码入口验证

使用原工程此前导出的 **61 张 BC7 + 12 张 RGBA8** 源图，新建独立目标和独立缓存。调用的是安装代码的实际批量转换函数，非直接调用实验包装。

| 测试 | 转码入口总时间 | 原生完成 | texconv 调用 |
|---|---:|---:|---:|
| 空目标、空产物缓存 | **11.603 s** | 61 张 BC7 | 1 次，仅 12 张 RGBA8 |
| 新空目标、已有产物缓存 | **1.865 s** | 61 张原生缓存命中 | 0 次；另 12 张普通缓存命中 |

这是**转码入口阶段**，不是完整 Blender 工程导出时间。冷轮缓存查找/源哈希约 2.919 s，原生批量阶段约 2.620 s；剩余 12 张未压缩 DDS 的 texconv、写出与存缓存约 5.235 s。并行任务的累计子阶段时间不能与外部墙钟直接相加。

验证结果：

- 冷/热轮全部 73 张 DDS 逐字节一致，进度回调最终为 73，目标文件齐全。
- 61 张 BC7 基础层压缩数据与此前已验证原型全部一致，继承其基础层 61/61 通过 98% 相似度、最低约 99.21% 的结果。
- 60 张完整 DDS 与此前原型一致；另 1 张带 sRGB 信息的 **UNORM 数据图**按现有 `--ignore-srgb` 规则修正了 mip 行为。本轮单独与实际 texconv 的 RGBA 准备结果核对，该图 3 级 mip 的 RGBA 差值为 **0**。
- 12 张未压缩 DDS 与更早正式导出基线逐字节一致。
- 新编码器使用独立二进制摘要构成缓存键，之前不同编码器/参数的缓存不会误用；支持沿用的 texconv 产物仍优先复用，避免无意义重编码。
- 本轮验证的 73 份产物已填入默认本机缓存。源图与缓存没有上传 GitHub。
